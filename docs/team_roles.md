## Collaboration Guidelines

- Git workflow: feature branches named `feature/<short-desc>`; open PRs to `main`; require at least one approver before merge
- Code reviews: reviewers verify functionality, tests and basic linting; small incremental PRs encouraged
- CI: run tests and linting on PRs (add when possible)
- Documentation: update `docs/` for design decisions; keep README up-to-date with run/deploy instructions
- Issue tracking: create issues for tasks and tag by type (`bug`, `enhancement`, `task`, `documentation`)
