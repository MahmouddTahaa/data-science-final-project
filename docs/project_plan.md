# Data Science Final Project - Project Plan

## Project Overview

This project involves analyzing the Ford GoBike dataset to create insights and develop an interactive dashboard application.

## Project Goal

**Develop an interactive data analysis dashboard website as per requirement document**

## Project Timeline

- **Sprint 1:** January 15 - January 29, 2025

## Dataset

- **Source:** Ford GoBike raw data (`fordgobike_raw.csv`)

## Project Structure

```
data-science-final-project/
├── data/
│   ├── processed/      # Processed datasets
│   └── raw/           # Raw datasets
├── docs/              # Project documentation
├── models/            # Trained ML models
├── notebooks/         # Analysis notebooks
├── src/               # Source code
└── utils/             # Utility functions
```

## Key Deliverables

1. Research and analysis of given topics
2. Complete project documentation
3. Dataset analysis following provided notebook
4. Clean and interactive UI (Dashboard)
5. Analysis pipelines
6. Deployed application
7. [Optional] Predictive ML Models

## Technology Stack

- Python
- Dash for Interactive Dashboard Creation
- Plotly Cloud for Deployment

## Success Criteria

- Dashboard is interactive with date/location filters and loads primary views within 3 seconds for typical queries
- EDA notebook(s) document key data quality issues and provide reproducible analysis steps
- Data processing pipelines produce clean, documented `data/processed/fordgobike_processed.csv`
- Application deployed and reachable via a public URL (Streamlit Cloud or Render)
- Project documentation covers roles, user stories, sprint notes, and a README with run instructions
- (Optional) A baseline predictive model (if developed) achieves reasonable performance (e.g., explained variance or RMSE within expected bounds for the chosen target) and is reproducible
